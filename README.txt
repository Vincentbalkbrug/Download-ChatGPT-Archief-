Publiceren via GitHub Pages:
1. Maak een nieuwe repository.
2. Upload ALLE bestanden uit deze map naar de hoofdmap van de repository.
3. Ga naar Settings > Pages.
4. Kies Deploy from a branch.
5. Kies branch main en map /root.
6. Sla op.
7. Open daarna de GitHub Pages-link in Safari op je iPhone.
8. Tik op Delen > Zet op beginscherm.

De gegevens worden lokaal op je toestel opgeslagen in de browser.
Gebruik regelmatig Export om een back-up te bewaren.
